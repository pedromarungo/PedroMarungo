## 01 / ABOUT

Self-taught developer with a background in software development and a growing focus on cybersecurity.

I'm interested in understanding how software works beneath the surface: how applications execute, how operating systems function, how programs interact with memory, and how vulnerabilities can be discovered and exploited.

My primary direction is **exploit development and vulnerability research**.

I prefer learning by understanding the underlying technology, experimenting with code, breaking things in controlled environments, and figuring out why they work the way they do.

## 05 / PHILOSOPHY

I don't want to simply memorize commands or follow tutorials.

I want to understand what happens underneath:

- What actually happens when code executes?
- How does a program interact with the operating system?
- How does memory work?
- How do applications communicate?
- Why do vulnerabilities exist?
- How can those vulnerabilities be reproduced and understood?

Understanding the mechanism matters more than memorizing the tool.
